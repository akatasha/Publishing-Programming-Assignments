## About the Project

This repository contains my programming activities for Introduction to Computing. It features a collection of simple web-based programs created using HTML, CSS, and JavaScript. Each activity focuses on applying fundamental programming concepts, including calculations, conditional statements, and loops, through practical exercises.

## Included Activities

1. **Unit Conversion Calculator**  
   A program that converts temperature and length measurements between different units, such as Celsius and Fahrenheit, and meters and feet.

2. **Income Tax Calculator**  
   A calculator that determines an individual's income tax based on the applicable Philippine tax brackets.

3. **Factorial, Summation, and Average Calculator**  
   A program that computes the factorial, sum, and average of the first N natural numbers using different looping structures, including `for`, `while`, and `do-while`.

4. **Basic Payroll Calculator**  
   A simple payroll program that calculates an employee's gross earnings using their hourly wage and total hours worked.

## Built With

- **HTML** – Used to structure the webpages.
- **CSS** – Used to style the interface and improve its appearance.
- **JavaScript** – Used to implement the program logic, calculations, and interactive features.

## Purpose

These activities apply the programming fundamentals discussed in class and provide an opportunity to practice developing interactive programs in JavaScript.
